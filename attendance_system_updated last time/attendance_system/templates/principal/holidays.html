Holiday Management

Holidays are automatically excluded from working days and attendance % for everyone they apply to -- no one is marked absent on a holiday.

Add Holiday / Vacation

Leave End Date blank for a single-day holiday. For a festival whose date changes every year (e.g. a Gujarati festival), just add/edit it here each year -- your change is always preserved even if you later import a new calendar.

Import Annual Calendar

Upload a CSV or Excel (.xlsx) file with columns: name, start_date, end_date (optional), class (optional -- leave blank for all classes). Dates can be YYYY-MM-DD or DD-MM-YYYY.

Priority rule: importing never overwrites or duplicates a holiday you already added or edited by hand -- any exact duplicate (same name, dates and class) is skipped automatically.
